# 来源接口

`GET /agenda` 返回带 `data-docket` 的公开议程条目。其文号标识议案，同一议案可换组、换日。
`GET /official` 返回各议案的当前条文、废止版本和各版本可用席位。 `public` 表示允许所有席位领取。仅列明指定席位时，其他席位无分发许可。条文版本在同一议案内唯一。
`GET /translations` 返回待领译稿条目。 `refs` 记录索引所指的原文版本，下载链接可能由原站复用。已下载的 JSON 原件在自身 `segments` 中逐段声明版本。原件与索引矛盾时，需能指出相关引用待复核。索引中缺语言记录表示该站本次没有条目，503 表示本次无从查验。
输入中的 `desks` 列出席位及要领取的语言。

/ack 提供席位收到的历史签出件和撤换确认。签出回执给出 issue 与收到的条文版本，撤换回执给出 issue、受影响的原文版本及秘书处 notice 编号。/official 中的 changes 使用 notice 标识原文或分发范围的变化。空确认表示尚未收到。issuedBefore 是值班开始时已签出的记录。
